THE HOUSE BENEATH THE WATER — VERCEL BUILD

The actual site is still plain HTML/CSS/JS and lives in this public/ folder.
For normal text edits, use:

  assets/js/edit-me.js

The p5 animations use a local copy generated during the Vercel build. The project-level START-HERE.md explains deployment and the new server-side pieces.

IMPORTANT EDITING SPOTS
- assets/js/edit-me.js        everyday text control panel
- assets/css/site.css         visual skin
- assets/js/ocean.js          underwater p5 animation
- assets/js/garden.js         garden p5 animation
- assets/js/site.js           house memory, pocket, heartbeat, shared interactions
- index.html                  main room and object navigation
- journal/index.html          weblog room
- drawer/index.html           art drawer
- grimoire/                   Rooted Stars pages
- creatures/ + stables/      creature / stable records

The house memory and treasure pocket are deliberately browser-local. No account or tracking service is involved.
